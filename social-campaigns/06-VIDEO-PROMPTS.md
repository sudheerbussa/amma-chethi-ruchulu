# Video prompts — bases (Google Veo / Flow / Gemini video)

**Rule:** Every post is a **complete paste pack**. Copy **PROMPT** (and **NEGATIVE** if the tool has a separate box). No need to append global rules from elsewhere.

**Edit later (manual):** voice-over, music duck, captions, end card with WhatsApp QR/link.

**Defaults**
- Aspect in prompt: **9:16** (Reels / Shorts)
- Length target after trim: **15–25s**
- Location language: Tenali
- Customer CTA (end card Canva/CapCut, not AI text): Order on WhatsApp → https://wa.me/919823583498?text=Hi%2C%20I%20want%20today%27s%20menu  
- Chef CTA: https://wa.me/918886128995?text=AMMA%20-%20I%20want%20to%20cook%20with%20you  
- Customer phone digits: only if you design that video to show them.

### Type codes

| Code | Meaning |
|------|---------|
| **IMG+VO** | Stills (each pack below) → CapCut zoom/slideshow + your VO |
| **V-silent+VO** | AI video: no dialogue/music in bake; add full VO later |
| **V-audio+VO** | Soft SFX/ambience allowed; mute dialogue if model speaks; duck bed under VO |
