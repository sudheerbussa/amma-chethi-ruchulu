# Image prompts — posters (Google / OpenAI)

**Rule:** Every post below is a **complete paste pack**. Do not hunt “global” sections — each block already embeds style, constraints, and negatives.

**Workflow:** Copy the whole `PROMPT` block (or Prompt + Negative separately if the tool has two fields) → generate **one** image → add Canva text → stop.

**Location filled:** Tenali. CTA on posters = text for Canva/QR, **not** AI-generated text.

**Customer number on image:** only if you deliberately need digits; default = WhatsApp QR/link in Canva (no phone in AI art).

---

## Field guide (every pack)

| Field | Paste where |
|-------|-------------|
| **PROMPT** | Main image prompt box (Google Imagen / Gemini / OpenAI) |
| **NEGATIVE** | Negative prompt field if available; else append: `Avoid: …` at end of PROMPT |
| **SETTINGS** | Aspect / quality knobs in the UI |
