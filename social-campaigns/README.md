# Amma Chethi Ruchulu — Social Media Campaign Pack

Documents to run **two separate** Meta/YouTube/Instagram campaigns:

| Campaign | Goal | Audience |
|----------|------|----------|
| **A — Customers** | Orders via WhatsApp | Local families, office workers, people who want home-style meals |
| **B — Home chefs** | Recruit Ammas / home cooks | Homemakers who cook well and want earnings from their kitchen |

## How to use this pack

1. Read **`01-BUSINESS-MODEL.md`** once (you + any freelancer / Cursor session).
2. Copy **`02-CURSOR-MASTER-PROMPT.md`** into a new Cursor chat when you want help drafting captions, refining prompts, or producing **one asset at a time**.
3. Pick a campaign → open **`03-`** or **`04-`** → choose **Post N**.
4. Generate **poster** from **`05-IMAGE-PROMPTS.md`** — each post is a full paste pack (PROMPT + NEGATIVE + SETTINGS).  
5. Generate **video base** from **`06-VIDEO-PROMPTS.md`** — same: every pack is self-contained (no hunting global rules).
6. Record or generate voice-over separately; do **music / VO / title overlap in CapCut, Premiere, or DaVinci** (manual).
7. Post captions from **`08-CAPTIONS-HASHTAGS.md`**.

Full one-asset checklist: **`07-PRODUCTION-WORKFLOW.md`**.

## Asset plan (per campaign)

Each campaign has **10 posts**. Every post ships in:

- **Poster** (static) — FB feed + IG feed (+ YT community / Shorts cover where useful)
- **Video** — IG Reels / FB Reels / YouTube Shorts (and longer YT optional notes)

Video production **types** (mix across the 10 posts):

| Code | Method | Audio in generator | Your edit |
|------|--------|--------------------|-----------|
| **IMG+VO** | Stills (AI images) + Ken Burns / slideshow | None from video tool | Add voice-over + optional music |
| **V-silent+VO** | AI video (no / mute bake-in audio) | Prefer silent or strip audio | Full VO + music under |
| **V-audio+VO** | AI video that already has SFX/ambience | Keep generated bed | Soften bed, layer VO on top |

Tools recommended in this pack:

- **Images:** Google (Imagen / Gemini image) or OpenAI (gpt-image / DALL·E family)
- **Video:** Google (Veo / Flow / Gemini video tools — whatever you currently use)
- **Edit:** CapCut or Desktop NLE — titles, captions, LOGO, dual-language lines

## Brand (campaign defaults)

| Item | Value |
|------|-------|
| Brand | **Amma Chethi Ruchulu** |
| Meaning cue | Flavours from mother / home hands (Telugu feel; use Telugu only where you can verify spelling) |
| USP | Named home cooks (Ammas), not restaurant frying |
| Order channel | WhatsApp (scheduled lunch / dinner — not 30-min “instant”) |
| Cook economics | ~70% of food gross to Amma (platform: remainder + delivery ops) |
| Visual direction | Home-kitchen cooking (steam, kadhai, natural light) + **sealed good disposable meal packs** for delivery truth; banana-leaf only as plating mood, not as packaging promise — **not** purple SaaS or cream bakery clichés |

## Production rule

**One poster or one video per work session.**  
Do not batch-generate 10 posts in one blur. Lock Post N before starting Post N+1 so brand and quality stay consistent.

## What is intentionally *not* in these docs

- Paid-media bidding strategy (boost later per winning creative)
- Exact locality / phone / WhatsApp link (fill placeholder `{{WA_LINK}}` / `{{CITY}}` / `{{PHONE}}` yourself)
- Legal microcopy for FSSAI claims on every ad (add if you publish hygiene/safety claims)

When ready: open `02-CURSOR-MASTER-PROMPT.md` and start with **Customer Post C01** or **Chef Post H01**.
