## Step-by-step on FoSCoS

1. Open [foscos.fssai.gov.in](https://foscos.fssai.gov.in)  
2. **Sign up / Login** with mobile + email → OTP  
3. Apply for **new Registration** (Basic / Form A)  
4. Select **Andhra Pradesh** → **Guntur** as needed  
5. Fill FBO details using the table above — **name + address match Udyam**  
6. Upload photo, ID, address proof  
7. Enter food product / kind of business  
8. Pay fee online (UPI / card)  
9. Submit → save **Application Reference Number**  
10. When approved → download certificate → note **14-digit FSSAI number**

Track status on the same portal. Approval is often a few working days (can vary).
