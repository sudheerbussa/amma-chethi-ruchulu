# Productized Content Engine — Feasibility Kit

Analysis of the **Sleeping Creators / DFY Social Media** productized service model (reference video + screenshots), aimed at deciding whether to build alone or with a collaborator.

## Source

- Video: [With AI Agents & AI Apps — Nikhil’s ~₹12L/month productised service](https://aifilmakersofficial.wistia.com/s/h5bl4u5fteqh5t7)
- Screenshots: `refs/` (captured from the same walkthrough)

## Offer snapshot (from video + transcript)

| Item | What they sell |
|------|----------------|
| Price | **₹5,000 → ~₹6,000/mo** (raised with demand) |
| Promise | Fully managed IG; one ~8‑min form; client effort ≈ 0 |
| Deliverables | Competitor scrape (10–12 peers), audit, **20–25 carousels** (~10 slides), **10 reels**, daily auto-post, comment→DM lead magnet, reporting |
| Ops rule | **No approval gate** — post first, feedback later; live in **24–48h** |
| Growth loop | **5 referrals → free month**; heavy **JV** inbound |
| Ops UI | Custom Content Engine; Claude Code + scheduling APIs |
| Scale claimed | ~165 enrolled / ~121 active in ~1 month; ~₹14L with 2 staff @ ₹20–25k (his numbers) |
