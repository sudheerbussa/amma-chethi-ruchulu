# Client onboarding checklist (copy into form)

Use with [06-RESEARCH-LEADS-RESULTS.md](06-RESEARCH-LEADS-RESULTS.md). Mark **R** = required for posting, **G** = required for growth/leads case study.

## Access (R)
- [ ] IG handle  
- [ ] Professional account confirmed  
- [ ] Facebook Page linked  
- [ ] Admin/OAuth path agreed (no password preferred)  
- [ ] Posting times (IST)  
- [ ] Auto-publish vs approve window  

## Brand (R)
- [ ] Display name  
- [ ] Profile photo file  
- [ ] Language  
- [ ] Template (`tweet_card_dark` default)  
- [ ] Colors (or accept black/white)  

## Offer & funnel (G)
- [ ] Primary offer + price band  
- [ ] ICP (who buys)  
- [ ] 3 pains / 3 outcomes  
- [ ] CTA keyword  
- [ ] Lead magnet type + asset or “create for me”  
- [ ] Booking / WhatsApp / bio link  
- [ ] 30/60/90 success definition  

## Voice & research seeds (G)
- [ ] Origin story  
- [ ] Proof points (truthful only)  
- [ ] 10 voice samples  
- [ ] **10–12 competitor/peer handles** (required — matches Sleeping Creators research method)  
- [ ] Topic blacklist  
- [ ] Approval mode: default **auto-post** (feedback after), unless client opts into approve window  

## Ops
- [ ] WhatsApp for emergencies  
- [ ] Report email  
- [ ] Testimonial permission if results hit agreed bar
