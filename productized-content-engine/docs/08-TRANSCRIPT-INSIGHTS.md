**Name:** creators want to sleep; content still ships from the backend.

| Price | Started **₹5,000/mo**; raised toward **₹6,000** as demand heated |
| Input | **One onboarding form** only |

| Platforms focus | Especially **Instagram** |
| Referral offer | Send **5 referrals** → **service free** for them |

### Deliverables he listed

1. **Market analysis** — client shares **10–12 competitors**; they scrape what’s working (winning posts/topics) and build strategy  
2. **Account audit** — competitors, gaps, missing strategy  
3. **20–25+ carousels** (~**10 slides** each)  
4. **10 reels** — often text/list “read caption” style (not only avatar essays)  
5. **Daily posting automation**  
6. **Comment → DM automation** — e.g. comment `GROW` / `X` → file in DM (lead magnet workflow + messaging)  
7. **Lead generation** included in the ₹5–6k package  
8. **Reporting** — live audit / competitor analysis, confirmation of daily posting, **monthly detailed analytics**

### Positioning vs typical agency

| Typical agency | Sleeping Creators |
|----------------|-------------------|
| ₹30–80k/mo | ₹5–6k |
| 10–12 day onboarding, Drive assets, Monday strategy calls | Form → content goes live |
| Shoots, approvals, delays | No approval, no delays |
| Alternate-day posting common | Daily posting |

Value line he uses: for ₹5k you often can’t even hire a reliable person who only uploads posts — here you get research, design, captions, automation, lead magnet system.

## What this means for *your* build

### Keep (still right)
- One form → research → carousels → daily publish → comment/DM lead magnet → reports  
- Automation-first; Claude Code / APIs / VPS  
- Carousel as volume engine  
- Track failures, incomplete profiles, analytics  

### Add / emphasize from transcript
1. **No-approval default** in product + contract (feedback channel, not gate)  
2. Form field: **10–12 competitor handles** (required for his research method)  
3. **Comment-keyword → DM file** as included deliverable (not optional Phase 3)  
4. **JV / referral mechanics** in the business plan (5 referrals = free month)  
5. Expectation script: activity + lead system first; optimize winners via analytics (80/20)  
6. Staffing model: **2 ops people** can run high volume *if* software works — align hiring with that, not 30-person agency  
7. Defer Omni/VO3 full avatar until carousel + DM + publish reliability is proven  

### Honest risk (from his own words)
- Many enrollments without completed forms → cash/ops mismatch  
- Results science still “figuring out” after month 1  
- Scale stories (14L, 165 clients, Superprofile 800–1000) are **sales-community narrative** — validate with your own pilots
