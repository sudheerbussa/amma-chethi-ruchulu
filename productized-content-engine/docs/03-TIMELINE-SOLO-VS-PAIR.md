# Timeline: solo vs two people

Assumes you already have general digital/AI skills (you do — WhatsApp bots, automation, content adjacent work). Timelines are **calendar weeks of focused part-time (15–25 hrs/wk)** unless marked full-time.

---

## Scope definition (important)

We are **not** timing “clone Sleeping Creators SaaS.”

We are timing:

1. **Offer MVP** — sell + deliver DFY IG content/leads with glue tools  
2. **Ops v1** — SOPs + templates + light automation  
3. **Optional Engine** — custom dashboard later  

---

## Solo (1 person)

| Phase | Duration | Outcome |
|-------|----------|---------|
| 0. Positioning + offer page + onboarding form | **1–2 weeks** | Clear niche, ₹ package, sample carousel pack |
| 1. Pipeline: 10–20 outreach / warm intros | **2–4 weeks** (overlaps) | First conversations |
| 2. Pilot clients (1–3), manual delivery | **3–6 weeks** | Case study + SOP draft |
| 3. Template system + hook library + Canva kits | **2–3 weeks** | Delivery time cut ~40–60% |
| 4. Automation (schedule, ManyChat, n8n) | **2–4 weeks** | “Autopilot-ish” for posting + lead capture |
| 5. Stabilize at 5–8 clients | **4–8 weeks** | Predictable monthly revenue |
| **Total to stable small book** | **~3–5 months** part-time | |
| Optional: custom Content Engine | **+4–9 months** | Only if needed |

**Solo full-time:** compress Offer MVP + first pilots to **~6–10 weeks**.

### Solo strengths
- Fast decisions, full margin, no partner conflict  
- Good fit if you can **sell** (even awkwardly) and QA content  

### Solo risks
- Sales + delivery bottleneck  
- Burnout around client 8–12 if reels stay manual  
- Building software alone before revenue is the #1 failure mode

## Two people

Pick the **pair type** carefully.

### Pair A — Operator + Producer (recommended)

| Role | Owns |
|------|------|
| Person 1 | Sales, onboarding, strategy, client WhatsApp, reporting |
| Person 2 | Carousels, reels edit, scheduling QA, templates |

| Phase | Duration | Outcome |
|-------|----------|---------|
| 0. Offer + brand + samples | **1 week** | Shared package doc |
| 1. Parallel sell + template factory | **2–3 weeks** | Pipeline + design system |
| 2. First 3–5 clients | **3–4 weeks** | Proof |
| 3. Automations + QA checklist | **2–3 weeks** | Scalable delivery |
| 4. 15–25 clients capacity | **6–10 weeks** | Real productized shop |
| **Total to meaningful revenue** | **~2.5–4 months** part-time | |
| Optional Engine | **+3–6 months** if one is technical | |

### Pair B — Two engineers / two builders

Faster SaaS, **slower money**. Only if one person explicitly owns outbound sales ≥50% of time.

### Pair C — You + VA only (not co-founder)

Hire editing VA at ₹15–30k/mo **after** 4–6 clients. Cheaper than equity partner.

## Side-by-side

| Milestone | Solo | Pair (Ops + Producer) |
|-----------|------|------------------------|
| First paid client | 3–8 weeks | 2–5 weeks |
| 5 clients | 2.5–4 months | 1.5–3 months |
| 15 clients | 5–9 months (or never without help) | 3–5 months |
| Custom app v1 | 6–12+ months | 4–8 months (if one builds) |
| Decision fatigue / conflict | Low | Medium (write roles early) |

---

## Recommendation for you

1. **Start solo for 8–12 weeks**  
   - Ship offer, get 2–3 pilots, write SOPs  
   - Spend ≤ ₹15k on tools  

2. **Collaborate when one of these is true**  
   - You have a waitlist / more demand than 15 hrs/wk delivery  
   - OR you refuse sales and found a closer who already has coach/D2C network  
   - OR you want to build the Engine and need a designer/editor so you stay on systems  

3. **Do not** take a 50/50 tech co-founder just to “build the Sleeping Creators app” before revenue.

### Simple rule

```text
If monthly delivery hours > 60% of your available time → add producer (hire or partner)
If pipeline is empty → do not add producer; fix sales alone
If tools are chaotic at 10+ clients → then consider custom engine / technical partner
```

## Suggested 12-week solo plan (concrete)

| Week | Focus |
|------|--------|
| 1 | Niche pick (1 ICP), offer one-pager, price, exclusions |
| 2 | 3 sample carousels + 1 reel style; landing + Tally form |
| 3–4 | Outreach 5/day or warm network; book discovery calls |
| 5–6 | Deliver pilot #1 end-to-end; log time per task |
| 7 | Template pack from pilot; cut weakest deliverables |
| 8–9 | Pilot #2–3; add ManyChat + scheduler |
| 10 | Public case study + raise price toward ₹7,999–9,999 |
| 11–12 | Decide: stay solo / hire VA / invite producer partner |

Revisit partner decision at **week 12 with data**, not at week 0 with screenshots.
