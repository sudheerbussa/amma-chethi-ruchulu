# Build path (phased)

Do not start by cloning `app.sleepingcreators.com`. Mirror the **client-facing promise**, not the internal UI.

## Phase 0 — Offer (week 1–2)

**Deliverables**
- One ICP (e.g. coaches / clinic owners / D2C founders — pick one)
- Package card:
  - ₹X/mo
  - N carousels, M reels, stories optional
  - posting cadence
  - 1 lead magnet + DM keyword → booking link
  - monthly report
- Onboarding form fields: business, ICP, offer, brand assets, IG access, goals
- 3 sample posts in your visual system

**Exit:** You can explain the offer in 60 seconds.

## Phase 1 — Manual AI-assisted delivery (week 2–6)

**Stack:** ChatGPT/Claude + Canva + CapCut + Drive + Notion + Meta scheduler or Late free

**Process**
1. Audit IG + 5 competitors (notes, not a product)
2. 30-day content pillars
3. Batch-create 7–14 days of content
4. Client async approval in WhatsApp (limit rounds)
5. Publish + screenshot proof

**Exit:** 1–3 pilots completed; time log known.

## Phase 2 — Productized ops (week 6–12)

**Add**
- Canva brand kit per client
- Hook library (100 hooks)
- n8n/Make: form → Drive folder → task row
- ManyChat flow: keyword → lead magnet → Cal.com
- Standard report template (followers, reach, top 3 posts, next experiments)

**Exit:** Delivery ≤ 6–8 hrs/client/month for standard package.

## Phase 3 — Capacity (month 3–6)

- VA editor or producer partner
- Raise price or add “Authority+” tier (avatar reels, LinkedIn, ads)
- Cap clients per person

## Phase 4 — Custom Content Engine (only if needed)

Build when **two** are true:
1. ≥10 active retainers  
2. Tool sprawl or publish failures cost real money/time  

**MVP modules (priority order)**
1. Clients + status (active/paused)  
2. Content calendar + draft/publish states  
3. Generate post (LLM + template IDs)  
4. Publish worker + retries + error log  
5. Simple analytics pull  
6. AI spend meter  

Tech suggestion aligned with your stack: **Next.js + Supabase/Postgres + Inngest/BullMQ + Meta or vendor publish API**.

## Success metrics (ignore vanity)

| Metric | Healthy early signal |
|--------|----------------------|
| Sales calls → paid | ≥20% |
| Time per client / month | Trending down |
| Client retention month 2 | ≥70% |
| Soft costs (tools) / revenue | <15% |
| Net promoter / renewals | Qualitative “I’d be sad to lose this” |

₹12L/mo is a **north star**, not a forecast. Plan to **₹50k–2L/mo** first year if execution is solid part-time.
