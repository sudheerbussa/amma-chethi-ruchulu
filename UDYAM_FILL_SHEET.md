## Step-by-step on the portal

1. Open https://udyamregistration.gov.in  
2. Choose **new registration** / **not yet registered as MSME** (exact label may vary).  
3. Enter **Aadhaar** → Validate → enter **OTP**.  
4. Consent / declare as per form.  
5. Select **Proprietorship**.  
6. Enter / validate **PAN**.  
7. Fill enterprise details using the table above — **name and address exactly as written**.  
8. Add bank details, NIC, employees, investment, turnover.  
9. Add **GSTIN** only if you have it.  
10. Submit.  
11. Download **Udyam Registration Certificate (PDF)**.  
12. Note the **URN** (Udyam Registration Number).
